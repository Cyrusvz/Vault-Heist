How to Play

  • Each vault hides a secret number. Type a guess and press Check!
  • You get limited tries and a countdown for every vault.
  • 🔥 Hints tell you how hot or cold your guess is.
  • 🌀 TWIST: in later vaults the code SHIFTS after every few wrong guesses!
  • 📡 Radar (once per vault) reveals if the code is odd or even.
  • 👻 In the last vault there are no higher/lower hints!
  • Faster wins with more tries left earn more points.
